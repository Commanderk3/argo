## create an `.env` file and set these
```
# Database Configuration
DB_NAME=argo_db
DB_USER=postgres
DB_PASSWORD=12345 // your DB password
DB_HOST=localhost
DB_PORT=5432

# File Paths
# Base directory for most scripts
BASE_DIR=C:\\Users\\krishna\\Documents\\argo\\dac\\incois  // your incois folder

# Base directory for DAC scanning (used in seed_floats.py)
DAC_BASE_DIR=C:\\Users\\krishna\\Documents\\argo\\dac // your dac folder
```
